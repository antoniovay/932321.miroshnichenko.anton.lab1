# Лабораторная работа 1. Основы HTML и структура веб-страницы
### Web-технологии

## Цель
Освоить базовую структуру HTML-документа, семантические теги, работу с текстом,
списками, ссылками и изображениями.

## Постановка задачи
Создать HTML-страницу «О себе», которая содержит следующие элементы:
- <header> – шапка с именем/фамилией студента и заголовком страницы.
- <main> – основной контент.
- Две секции <section>: «Навыки» (маркированный список) и «Проекты»
(нумерованный список из 3–4 пунктов).
- <aside> – боковая панель с краткой информацией (например, «Любимые
технологии»).
- <footer> – подвал с копирайтом и годом.
- Одно изображение (портрет/аватар) с атрибутами src, alt, width, height.
- Форма обратной связи: поля «Имя» (type="text"), «Email» (type="email"),
«Сообщение» (<textarea>), кнопка отправки. У всех полей – атрибуты name и
placeholder.

## Вариант 14
Тема «Дизайнер и визуализатор». В «Навыках» – дизайнерские навыки
(например, работа с макетами, понимание типографики, цветовая теория). В «Проектах» –
3–4 дизайн-проекта (логотипы, интерфейсы, плакаты). В <aside> – любимый стиль дизайна
(минимализм, ретро, брутализм). Цветовая гамма: пастельно-розовая с контрастными
акцентами.
